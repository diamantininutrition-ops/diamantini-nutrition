2) REDIRECTIONS STATIQUES DES ANCIENNES URL LÉGALES
--------------------------------------------------

GitHub Pages ne sert pas les redirections TanStack (src/routes/mentionslegales.tsx et src/routes/politiquedeconfidentialite.tsx) : aujourd’hui /mentionslegales et /politiquedeconfidentialite (avec ou sans slash) répondent 404. Laisse ces routes TanStack en place pour l’aperçu en développement, mais ajoute des fichiers HTML statiques dans public/, comme pour /contact/. Sur GitHub Pages, un dossier avec index.html couvre l’URL avec slash, et l’URL sans slash est redirigée automatiquement en 301 vers celle avec slash.

Crée exactement ces deux fichiers :

- public/mentionslegales/index.html → https://diamantini-nutrition.fr/mentions-legales/
- public/politiquedeconfidentialite/index.html → https://diamantini-nutrition.fr/politique-de-confidentialite/

Reproduis le modèle déjà utilisé dans public/contact/index.html (titre « Redirection », noindex, follow, canonical, meta refresh, location.replace). Modèle exact, en remplaçant uniquement URL_CIBLE :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Redirection</title>
  <meta name="robots" content="noindex, follow">
  <link rel="canonical" href="URL_CIBLE">
  <meta http-equiv="refresh" content="0; url=URL_CIBLE">
  <script>location.replace("URL_CIBLE")</script>
</head>
<body>
  <p><a href="URL_CIBLE">URL_CIBLE</a></p>
</body>
</html>

Ces fichiers doivent se retrouver tels quels dans le build final (par exemple .vercel/output/static/mentionslegales/index.html et .../politiquedeconfidentialite/index.html) et ne pas être écrasés par le prerender. Ne crée pas d’entrée sitemap pour ces redirections.
